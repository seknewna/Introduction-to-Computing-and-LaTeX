bash-scripting/scripts/04-case-arrays-substitution.sh 
#!/usr/bin/env bash
#
# Chapter 04 — Case Statements, Arrays & Substitution
# Real commands: case/esac, indexed & associative arrays, IFS,
# $(...) command substitution, $((...)) arithmetic, <(...) process sub.

for name in dave bill anyone; do
    case "$name" in
        d*)  echo "matched d*: $name" ;;
        b*)  echo "matched b*: $name" ;;
        *)   echo "matched *: $name"  ;;
    esac
done

echo
echo "Indexed array — note *the difference* between [*] and [@]:"
array=(foo bar baz)
echo "element 0: ${array[0]}"
echo "last element: ${array[-1]}"
echo "all (as one word): ${array[*]}"
echo "all (as separate words): ${array[@]}"

echo
echo "Associative array — string keys instead of positions:"
declare -A capitals=([France]=Paris [Japan]=Tokyo)
for key in "${!capitals[@]}"; do
    echo "$key is ${capitals[$key]}"
done

echo
echo "Command substitution — prefer \$(...) over legacy backticks:"
thing=$(whoami)
echo "thing is $thing"

echo
echo "Arithmetic expression:"
i=0
((i++))
echo "i is $i"
echo "2 + 2 = $((2 + 2))"

echo
echo "Process substitution treats a command's output like a file:"
diff <(printf 'a\nb\n') <(printf 'a\nc\n') || true

## What is R?

R is a statistical programming language created in 1992 by Ross Ihaka and
Robert Gentleman at the University of Auckland, New Zealand, and first
released as version 1.0 in February 2000. Its name comes from the initials

history.

# Outlier Detection

## The Inter-Quartile Range (IQR) method

A value outside the interval below is treated as an outlier:

$$[Q_1 - 1.5\times IQR,\ Q_3 + 1.5\times IQR]$$

where $Q_1$/$Q_3$ are the 25th/75th percentiles and $IQR = Q_3 - Q_1$.

```{r fig.height=4, fig.width=5}
x <- c(19.103, 19.632, 22.494, 20.113, 10.5, 22.744, 20.737, 17.976,
       18.901, 192.87, 21.959, 0.001, 20.641, 20.177, 19.111, 22.859,
       207.97, 16.853, 21.122, 19.244, 18.291, 19.651, 18.358, 18.834, 19)

x_copy <- x
boxplot(x_copy, main = "Before handling outliers")
```

```{r}
Q <- as.numeric(quantile(x, probs = c(0.25, 0.5, 0.75)))
d <- as.data.frame(t(Q))
names(d) <- paste0("Q", 1:length(Q))
d$IQR      <- d$Q3 - d$Q1
d$LowerLim <- d$Q1 - 1.5 * d$IQR
d$UpperLim <- d$Q3 + 1.5 * d$IQR
d
```

Flagging every value as an outlier or not:
```{r}
(d_out <- data.frame(x = x, outlier = x < d$LowerLim | x > d$UpperLim))
```

Two equivalent ways to pull out just the outliers:
```{r}
x[d_out$outlier]                                  # using our own table
(bxpt <- boxplot(x, range = 1.5, plot = FALSE))$out # using boxplot()'s own $out
```

## Imputing the outliers

Treat outliers as missing, then fill them with the mean of everything else:
```{r}
x[d_out$outlier] <- NA
x[is.na(x)] <- mean(x, na.rm = TRUE)
```

```{r fig.height=4, fig.width=7}
par(mfrow = c(1, 2))
boxplot(x_copy, main = "Before\nhandling outliers", cex.main = 0.8)
boxplot(x, main = "After\nhandling outliers", col = "green", cex.main = 0.8)
```

No more outliers remain after imputation.

## 2. Solve a quadratic equation and comment on its discriminant

For $ax^2 + bx + c = 0$:

```
                  ┌─ discriminant > 0 → two distinct real roots
compute disc = b² - 4ac ─┤─ discriminant = 0 → one repeated real root
                  └─ discriminant < 0 → two complex conjugate roots
```

```{r}
solve_quadratic <- function(a, b, c) {
  if (a == 0) stop("a must be non-zero for a quadratic equation")

  disc <- b^2 - 4 * a * c

  if (disc > 0) {
    message("Two distinct real roots")
    roots <- c((-b + sqrt(disc)) / (2 * a), (-b - sqrt(disc)) / (2 * a))
  } else if (disc == 0) {
    message("One repeated real root")
    roots <- -b / (2 * a)
  } else {
    message("Two complex conjugate roots")
    real_part <- -b / (2 * a)
    imag_part <- sqrt(-disc) / (2 * a)
    roots <- c(complex(real = real_part, imaginary = imag_part),
               complex(real = real_part, imaginary = -imag_part))
  }
  roots
}

solve_quadratic(1, -3, 2)  # disc > 0
solve_quadratic(1, 2, 1)   # disc == 0
solve_quadratic(1, 0, 1)   # disc < 0
```

# The Pipe

Two pipe operators are common in R:

* `%>%` from the `magrittr` package (loaded with `tidyverse`/`dplyr`)

# Detecting Matches

`grepl()` returns `TRUE`/`FALSE` for each element:
```{r}
grepl("[0-9]+", text)
```

`grep()` returns matching positions, or the matching strings themselves
with `value = TRUE`:
```{r}
grep("[0-9]+", text)

```

# Replacing Matches

`sub()` replaces only the first match per string; `gsub()` replaces all:
```{r}
sub("[0-9]+", "#", text)
gsub("[0-9]+", "#", text)
```

# Extracting Matches

`regexpr()` finds the *first* match's position; `regmatches()` pulls out
the actual matched text:
```{r}
m <- regexpr("[0-9]+", text)
regmatches(text, m)
```

`gregexpr()` + `regmatches()` extracts *every* match per string:
```{r}
mg <- gregexpr("[0-9]+", text)
regmatches(text, mg)
```

# A Practical Pattern: Validating an Email

```{r}
grepl("^[A-Za-z]+@[A-Za-z]+\\.[a-z]+$", text)
```

# Common Building Blocks

| Pattern | Matches |
|---|---|
| `[0-9]` or `\\d` | any digit |
| `[a-zA-Z]` | any letter |
| `.` | any single character |
| `+` | one or more of the previous token |
| `*` | zero or more of the previous token |
| `^` / `$` | start / end of the string |
| `\\s` | whitespace |
| `\|` | alternation ("or") |

# Principal Component Analysis

Chapter 3 walked through PCA by hand: center the data, eigen-decompose its
covariance matrix, and project onto the top eigenvectors. In practice,
`prcomp()` does all of that for you, plus proper scaling:
```{r}
data(iris)
pca <- prcomp(iris[, -5], center = TRUE, scale. = TRUE)
summary(pca)
```

`Proportion of Variance` shows how much information each component
captures — here the first two components already explain most of the
spread in the data.
```{r fig.height=4, fig.width=6}
plot(pca$x[, 1:2], col = iris$Species, pch = 16,
     xlab = "PC1", ylab = "PC2", main = "iris projected onto PC1/PC2")
legend("topright", legend = levels(iris$Species),
       col = 1:3, pch = 16, bty = "n")
```

# Clustering

## K-means

Partitions data into `k` groups by minimizing within-cluster distance.
Being unsupervised, it never sees `Species` — comparing its output to the
real labels afterward is just for evaluation.
```{r}
set.seed(1)
km <- kmeans(iris[, -5], centers = 3, nstart = 10)
table(cluster = km$cluster, species = iris$Species)
```

## Hierarchical clustering

Builds a tree of nested clusters instead of a single flat partition:
```{r fig.height=4, fig.width=7}
d <- dist(iris[1:20, -5]) # a small subset, so the dendrogram stays readable
hc <- hclust(d, method = "complete")
plot(hc, main = "Hierarchical clustering (first 20 flowers)")

cutree(hc, k = 3) # cut the tree into 3 groups
```

# K-Nearest Neighbor (KNN)

A supervised classifier: label a new point by majority vote among its `k`
closest neighbors in the training data.
```{r message=FALSE}
library(class)
set.seed(1)
idx <- sample(1:nrow(iris), 0.7 * nrow(iris))
train <- iris[idx, ]
test  <- iris[-idx, ]

pred <- knn(train[, -5], test[, -5], cl = train$Species, k = 5)
mean(pred == test$Species) # accuracy on the held-out test set
table(predicted = pred, actual = test$Species)
```

# Simple Linear Regression

Already covered in Chapter 6's simulated-data example
(`z ~ x`, fitted with `lm()`). A quick recap on `iris`:
```{r}
lr <- lm(Petal.Length ~ Petal.Width, data = iris)
coef(lr)
```
Each additional cm of petal width is associated with roughly
`r round(coef(lr)[[2]], 2)` cm more petal length.

# Logistic Regression

For a categorical (here, binary) outcome, swap `lm()` for `glm()` with
`family = binomial`. Predicting *virginica* vs. *versicolor* from sepal
measurements:
```{r}
sub <- subset(iris, Species %in% c("versicolor", "virginica"))
sub$is_virginica <- factor(ifelse(sub$Species == "virginica", 1, 0))

logit <- glm(is_virginica ~ Sepal.Length + Sepal.Width, data = sub, family = binomial)
summary(logit)$coefficients
```

Turning predicted probabilities into class predictions at a 0.5 threshold:
```{r}
pred_prob  <- predict(logit, type = "response")
pred_class <- ifelse(pred_prob > 0.5, 1, 0)

mean(pred_class == sub$is_virginica) # accuracy
table(predicted = pred_class, actual = sub$is_virginica)
```

# %% [markdown]
# ### Eigenvalues and eigenvectors
# The eigenvalues $\lambda$ of a square matrix $A$ solve
# $\det(A - \lambda I) = 0$. They are the basis of Principal Component Analysis.

# %%
S = np.array([[2., -1., 0.],
              [-1., 2., -1.],

print(np.round(values, 4))
print(np.round(vectors.T @ S @ vectors, 4))   # a diagonal matrix of the eigenvalues

# %% [markdown]
# ## Worked exercise: PCA by hand on the iris data
# 1. Keep the four numeric columns.
# 2. Centre every column.
# 3. Eigen-decompose `X.T @ X`.
# 4. Project onto the first two eigenvectors.

# %%
from sklearn.datasets import load_iris
from sklearn.decomposition import PCA

X = load_iris().data                       # 150 flowers x 4 measurements
col_means = X.mean(axis=0)
print(np.round(col_means, 3))

Xc = X - col_means                         # centred data
cov = Xc.T @ Xc
eigvals, eigvecs = np.linalg.eigh(cov)     # eigenvalues in ascending order
order = np.argsort(eigvals)[::-1]          # sort from largest to smallest
eigvals, eigvecs = eigvals[order], eigvecs[:, order]
print(np.round(eigvals, 3))

projection = Xc @ eigvecs[:, :2]
print(np.round(projection[:3], 3))

# %% [markdown]
# This is exactly what scikit-learn's `PCA` does (the sign of an axis is
# arbitrary, so we compare absolute values):

import numpy as np
import pandas as pd

# %% [markdown]
# ## Missing values (`NaN`)
# Missing numbers are represented by `np.nan` ("not a number"; R: `NA`).

# %%
x = np.array([np.nan, 1, 2, np.nan, 3, np.nan, 3.55])

print(np.where(np.isnan(x))[0])        # positions of the missing values
print(np.where(x >= 2)[0])             # NaN compares as False, so it drops out
print(np.where(~np.isnan(x))[0])       # positions that are NOT missing
print(np.mean(x), np.nanmean(x))       # NaN spreads through a mean; nanmean ignores it

# %% [markdown]
# Replace the missing values with the mean of the others:

# %%

print(x)

# %% [markdown]
# pandas has dedicated tools: `isna`, `fillna`, `dropna`, `interpolate`.

# %%

print(s.isna().sum(), "missing")
print(s.fillna(s.mean()).tolist())
print(s.dropna().tolist())
print(s.interpolate().tolist())

# %% [markdown]
# ## Missing values created by conversion
# Converting messy text to numbers fails for anything that is not a clean number:

# %%
raw = pd.Series(["2", "1", "2", "7", "$8", "3", "2.5", "9", "2,7"])
y = pd.to_numeric(raw, errors="coerce")        # bad values become NaN
print(y.tolist())
print(raw[y.isna()].tolist())                  # the entries that failed

# %% [markdown]
# Clean the offending characters first, then convert:

# %%
messy = pd.Series(["2", "1", "2", ",7", "$8", "3", "&2.5", "9", "2,7"])
clean = (messy.str.replace(r"[$&]", "", regex=True)      # drop currency / junk symbols
              .str.replace(",", ".", regex=False))       # decimal comma -> dot
print(pd.to_numeric(clean).tolist())

# %% [markdown]
# ## Outlier detection: the IQR method
# A value is an outlier if it lies outside
# $$[Q_1 - 1.5\times IQR,\; Q_3 + 1.5\times IQR]$$
# where $IQR = Q_3 - Q_1$.

# %%
x = np.array([19.103, 19.632, 22.494, 20.113, 10.5, 22.744, 20.737, 17.976,
              18.901, 192.87, 21.959, 0.001, 20.641, 20.177, 19.111, 22.859,
              207.97, 16.853, 21.122, 19.244, 18.291, 19.651, 18.358, 18.834, 19])
x_original = x.copy()

plt.boxplot(x_original)
plt.title("Before handling outliers")
plt.show()

# %%
q1, q2, q3 = np.percentile(x, [25, 50, 75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print(f"Q1={q1:.3f}  Q3={q3:.3f}  IQR={iqr:.3f}  limits=({lower:.2f}, {upper:.2f})")

is_outlier = (x < lower) | (x > upper)
print(x[is_outlier])                    # the outliers themselves

# %% [markdown]
# ### Imputing the outliers
# Treat them as missing and fill them with the mean of the remaining values.

# %%
x[is_outlier] = np.nan
x[np.isnan(x)] = np.nanmean(x)

fig, axes = plt.subplots(1, 2, figsize=(8, 4))
axes[0].boxplot(x_original)
axes[0].set_title("Before")
axes[1].boxplot(x)
axes[1].set_title("After")
plt.tight_layout()
plt.show()

# ### 2. Solve a quadratic equation and comment on its discriminant
# For $ax^2+bx+c=0$ the discriminant is $\Delta=b^2-4ac$:
# * $\Delta>0$ — two distinct real roots
# * $\Delta=0$ — one repeated real root
# * $\Delta<0$ — two complex conjugate roots

# %%
import math


def solve_quadratic(a, b, c):
    if a == 0:
        raise ValueError("a must be non-zero for a quadratic equation")
    delta = b ** 2 - 4 * a * c
    if delta > 0:
        print("Two distinct real roots")
        return ((-b + math.sqrt(delta)) / (2 * a), (-b - math.sqrt(delta)) / (2 * a))
    if delta == 0:
        print("One repeated real root")
        return (-b / (2 * a),)
    print("Two complex conjugate roots")
    real, imag = -b / (2 * a), math.sqrt(-delta) / (2 * a)
    return (complex(real, imag), complex(real, -imag))


print(solve_quadratic(1, -3, 2))   # delta > 0
print(solve_quadratic(1, 2, 1))    # delta = 0
print(solve_quadratic(1, 0, 1))    # delta < 0

import pandas as pd

# ## Frequency table of a categorical variable
# `.pipe()` lets you put your own function inside a chain.

# %%
gender = pd.Series(["Female", "Male", "Male", "Female", "Female", "Male"])

table = (
    gender.value_counts()
          .rename_axis("Gender")
          .reset_index(name="Count")
          .assign(Rel_freq=lambda t: (t["Count"] / t["Count"].sum()).round(2))
)
print(table)

def percent(frame, column):
    return frame.assign(**{column + "_pct": (frame[column] * 100).round(0)})

print(table.pipe(percent, "Rel_freq"))

plt.ylabel("Relative frequency")

# ## Reshaping: wide to long and back (R: reshape2 / tidyr)

# %%
stats = df.groupby("species").agg(["mean", "std"])      # columns are (variable, statistic)
print(stats.round(2))

# wide -> long: one row per species / variable / statistic
flat = stats.copy()
flat.columns = [f"{var}|{stat}" for var, stat in flat.columns]       # e.g. "petal_length|mean"
long = flat.reset_index().melt(id_vars="species", value_name="value")
long[["variable", "metric"]] = long["variable"].str.split("|", expand=True)
long = long[["species", "variable", "metric", "value"]]
print(long.head(6).round(2))

# long -> wide again
wide = long.pivot(index=["species", "variable"], columns="metric", values="value").reset_index()
wide["std_error"] = wide["std"] / np.sqrt(len(df))      # standard error of the mean
print(wide.round(3).head(4))

fig, axes = plt.subplots(1, 4, figsize=(12, 3.2), sharey=False)

# %%
import re

text = ["dave@example.com", "call 555-1234", "no match here", "ID: R2024-001"]

# %% [markdown]
# ## Detecting matches
# `re.search` finds a pattern *anywhere* in a string and returns a match object
# (or `None`).

# %%
print([bool(re.search(r"[0-9]+", t)) for t in text])
print([t for t in text if re.search(r"[0-9]+", t)])        # keep the matching strings

# %% [markdown]
# ## Replacing matches
# `re.sub` replaces **every** match; add `count=1` to replace only the first.

# %%
print([re.sub(r"[0-9]+", "#", t) for t in text])
print([re.sub(r"[0-9]+", "#", t, count=1) for t in text])

# %% [markdown]
# ## Extracting matches
# `re.findall` returns every match; `match.group()` returns the text of one.

# %%
print([re.findall(r"[0-9]+", t) for t in text])
print([m.group() if (m := re.search(r"[0-9]+", t)) else None for t in text])

# %% [markdown]
# ## Capturing parts of a match with groups

# %%
m = re.search(r"(?P<user>[\w.]+)@(?P<domain>[\w.]+)", "write to dave@example.com today")
print(m.group("user"), m.group("domain"), m.span())

# %% [markdown]
# ## A practical pattern: validating an email address
# `re.fullmatch` requires the *whole* string to match.

# %%
email_pattern = re.compile(r"[A-Za-z0-9._-]+@[A-Za-z0-9-]+\.[A-Za-z]{2,}")

for candidate in ["dave@example.com", "bad.email@@x", "no-at-sign.com", "user@nodot", "a.b@c.org"]:
    print(f"{candidate:20s} {bool(email_pattern.fullmatch(candidate))}")

# %% [markdown]
# ## Common building blocks
#
# | Pattern | Matches |
# |---|---|
# | `[0-9]` or `\d` | any digit |
# | `[a-zA-Z]` | any letter |
# | `.` | any single character |
# | `+` | one or more of the previous token |
# | `*` | zero or more of the previous token |
# | `^` / `$` | start / end of the string |
# | `\s` | whitespace |

What Is LaTeX?Qu’est-ce que LaTeX ?

Most word processors are WYSIWYG — what you see is what you get. You click, drag, and format a page directly, and the tool shows you the result as you go.La plupart des traitements de texte sont WYSIWYG — « ce que vous voyez est ce que vous obtenez ». Vous cliquez, faites glisser et mettez en forme la page directement, et l’outil vous montre le résultat au fur et à mesure.

LaTeX works the opposite way. You write a plain text file full of commands that describe what things are — a section, a table, an equation — not how they should look pixel-by-pixel. A program called a TeX engine then reads that file and compiles it into a finished PDF.LaTeX fonctionne à l’inverse. Vous écrivez un fichier texte brut rempli de commandes qui décrivent ce que sont les choses — une section, un tableau, une équation — et non leur apparence au pixel près. Un programme appelé moteur TeX lit ensuite ce fichier et le compile en un PDF final.

The upshot: you focus on content and structure, and LaTeX handles the visual formatting for you, consistently, every time.En résumé : vous vous concentrez sur le contenu et la structure, et LaTeX s’occupe de la mise en forme visuelle, de façon cohérente, à chaque fois.

Why Learn LaTeX?Pourquoi apprendre LaTeX ?

  • Handles complex math, technical notation, and large tables far more gracefully than a word processor.Gère les formules complexes, les notations techniques et les grands tableaux bien plus élégamment qu’un traitement de texte.

# One idea to practice with: the basic reproduction number

The basic reproduction number $R_0$ is the average number of people one
infectious person infects in a fully susceptible population. In the simplest

At the start of an outbreak, almost everyone is susceptible, so cases grow
roughly exponentially:

$$I(t) \approx I_0\, e^{rt}$$

The growth rate $r$ can be estimated from data, and from it the
**doubling time** $T_d = \ln(2)/r$.

# Simulate daily case counts

We pretend the true growth rate is $r = 0.15$ per day, starting from 5 cases,
and add Poisson noise because real counts are never perfectly smooth.

```{r}
set.seed(1)
r_true <- 0.15
day <- 0:29
cases <- rpois(length(day), lambda = 5 * exp(r_true * day))
data <- data.frame(day, cases)
head(data)
```

# Estimate the growth rate

Taking logs turns the exponential curve into a straight line:
$\log I(t) = \log I_0 + r\,t$. So a linear regression of `log(cases)` on `day`
estimates $r$ as the slope.

```{r}
fit <- lm(log(cases) ~ day, data = data)
r_hat <- unname(coef(fit)["day"])
r_hat                       # close to the true value 0.15
log(2) / r_hat              # estimated doubling time in days
log(2) / r_true             # true doubling time
```

"""
MathEpi 01 - Exponential growth and doubling time

At the start of an outbreak almost everyone is susceptible, so cases grow
roughly exponentially:   I(t) ~ I0 * exp(r * t)
The growth rate r can be estimated from data, and the doubling time is
    T_d = ln(2) / r

import numpy as np
import matplotlib.pyplot as plt

# Simulate daily case counts: true r = 0.15 per day, 5 cases on day 0,
# plus Poisson noise (real counts are never perfectly smooth).
rng = np.random.default_rng(1)          # (R: set.seed(1))
r_true = 0.15
day = np.arange(30)                      # days 0..29

#     log I(t) = log I0 + r * t
# so a straight-line fit of log(cases) against day gives r as the slope.

r_hat = slope
print(f"estimated r      = {r_hat:.3f}   (true {r_true})")
print(f"doubling time    = {np.log(2) / r_hat:.2f} days")
print(f"true doubling    = {np.log(2) / r_true:.2f} days")

# Plot data and fit on a log scale (a straight line = exponential growth)
plt.semilogy(day, cases, "o", label="Observed")
plt.semilogy(day, np.exp(intercept + slope * day), "r-", label="Fitted")
plt.xlabel("Day")
plt.ylabel("Daily cases (log scale)")
plt.legend()
plt.show()

The SIR model splits a population of size $N$ into three compartments:
**S**usceptible, **I**nfectious, and **R**ecovered (or removed).

$$
\frac{dS}{dt} = -\beta \frac{S I}{N}, \qquad
\frac{dI}{dt} = \beta \frac{S I}{N} - \gamma I, \qquad
\frac{dR}{dt} = \gamma I
$$

Susceptibles become infectious at rate $\beta S I / N$; infectious people
recover at rate $\gamma$. The three equations add up to zero, so the total
population $N$ is constant.

# Solve it numerically with `deSolve`

```{r}
library(deSolve)

sir <- function(time, state, parms) {
  with(as.list(c(state, parms)), {
    dS <- -beta * S * I / N
    dI <-  beta * S * I / N - gamma * I
    dR <-  gamma * I
    list(c(dS, dI, dR))
  })
}

N     <- 1000
init  <- c(S = N - 1, I = 1, R = 0)
parms <- c(beta = 0.5, gamma = 0.2, N = N)
times <- seq(0, 120, by = 1)

out <- as.data.frame(ode(y = init, times = times, func = sir, parms = parms))
```

"""
MathEpi 02 - The SIR model

Susceptible -> Infectious -> Recovered, in a population of size N:

    dS/dt = -beta * S * I / N
    dI/dt =  beta * S * I / N - gamma * I
    dR/dt =  gamma * I

Needs: numpy, scipy, matplotlib
"""
import numpy as np
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt


def sir(t, y, beta, gamma, N):
    S, I, R = y
    dS = -beta * S * I / N
    dI = beta * S * I / N - gamma * I
    dR = gamma * I
    return [dS, dI, dR]


N = 1000
beta, gamma = 0.5, 0.2
y0 = [N - 1, 1, 0]                       # S, I, R at time 0
days = np.arange(0, 121)                 # 0, 1, ..., 120

# rtol sets how accurately the solver works; a tight value gives the same
# numbers as R's deSolve
sol = solve_ivp(sir, (0, 120), y0, args=(beta, gamma, N), rtol=1e-8, t_eval=days)
S, I, R = sol.y

plt.plot(sol.t, S, "b", label="S")
plt.plot(sol.t, I, "r", label="I")
plt.plot(sol.t, R, "g", label="R")
plt.xlabel("Day")
plt.ylabel("People")
plt.title("SIR epidemic")
plt.legend()
plt.show()

print(f"peak infectious     = {I.max():.0f}")
print(f"peak day            = {sol.t[I.argmax()]:.0f}")
print(f"total ever infected = {R[-1]:.0f}")

Three quantities summarise most of what the SIR model says about an outbreak.

* **Basic reproduction number:** $R_0 = \beta/\gamma$. An outbreak can take
  off only if $R_0 > 1$.
* **Herd immunity threshold:** the fraction of the population that must be
  immune so that $R_0 \times (\text{fraction susceptible}) \le 1$, i.e.
  $1 - 1/R_0$.
* **Final size:** the fraction $z$ of the population ever infected, which
  solves $z = 1 - e^{-R_0 z}$ (when almost everyone starts susceptible).

```{r}
beta <- 0.5
gamma <- 0.2
```

# Solving for the final size

The final-size equation has no closed-form solution, so we find its root
numerically with `uniroot()`.

```{r}
final_size <- function(R0) {
  if (R0 <= 1) return(0)                       # no major outbreak
  uniroot(function(z) z - (1 - exp(-R0 * z)),
          lower = 1e-6, upper = 1)$root
}
```

"""
MathEpi 03 - R0, herd immunity and final size

  R0                = beta / gamma         (an outbreak needs R0 > 1)
  herd immunity     = 1 - 1 / R0
  final size z      solves   z = 1 - exp(-R0 * z)
"""
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import brentq
import matplotlib.pyplot as plt

beta, gamma = 0.5, 0.2
R0 = beta / gamma
print(f"R0 = {R0},  herd immunity threshold = {1 - 1 / R0:.2f}")


# The final-size equation has no closed form, so find its root numerically
# (R: uniroot).
def final_size(R0):
    if R0 <= 1:
        return 0.0
    return brentq(lambda z: z - (1 - np.exp(-R0 * z)), 1e-6, 1)


print(f"final size from the equation = {final_size(R0):.4f}")


# Check against a simulated epidemic
def sir(t, y, beta, gamma, N):
    S, I, R = y
    return [-beta * S * I / N, beta * S * I / N - gamma * I, gamma * I]


N = 1000

                rtol=1e-8, t_eval=np.arange(0, 301))
print(f"final size from the simulation = {sol.y[2, -1] / N:.4f}")

Many infections have a **latent period**: a person is infected but not yet
infectious. The SEIR model adds an **E**xposed compartment:

$$
\frac{dS}{dt} = -\beta \frac{SI}{N}, \quad
\frac{dE}{dt} = \beta \frac{SI}{N} - \sigma E, \quad
\frac{dI}{dt} = \sigma E - \gamma I, \quad
\frac{dR}{dt} = \gamma I
$$

where $\sigma = 1/(\text{latent period})$. Here we use a 5-day latent period
($\sigma = 0.2$).


Differential equations describe the average behaviour of a big population.
When only a few people are infected, chance matters: a single case may infect
nobody and the outbreak dies out immediately.

The **Reed-Frost** chain-binomial model captures this in discrete generations.
If $I_t$ people are infectious and each pair of people has probability $p$ of
a transmitting contact, a susceptible escapes infection with probability
$(1-p)^{I_t}$. So

$$ I_{t+1} \sim \text{Binomial}\big(S_t,\; 1 - (1-p)^{I_t}\big). $$

```{r}
reed_frost <- function(N = 200, I0 = 1, p = 0.01) {
  S <- N - I0
  I <- I0
  total <- I0
  while (I > 0) {
    new_I <- rbinom(1, S, 1 - (1 - p)^I)
    S <- S - new_I
    total <- total + new_I
    I <- new_I
  }
  total                             # total number ever infected
}

N <- 200; p <- 0.01
R0 <- (N - 1) * p                   # about 2
```

"""
MathEpi 06 - Stochastic epidemics (Reed-Frost chain binomial)

With few infected people, chance matters. In discrete generations, if I_t
people are infectious and each pair has probability p of a transmitting
contact, a susceptible escapes with probability (1 - p)**I_t, so

    I_{t+1} ~ Binomial(S_t, 1 - (1 - p)**I_t)
"""
import numpy as np
from scipy.optimize import brentq
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)


def reed_frost(N=200, I0=1, p=0.01):
    S, I, total = N - I0, I0, I0
    while I > 0:
        new_I = rng.binomial(S, 1 - (1 - p) ** I)
        S -= new_I
        total += new_I
        I = new_I
    return total                      # total number ever infected


N, p = 200, 0.01
R0 = (N - 1) * p                      # about 2
print("R0 =", R0)

# Run many outbreaks
sizes = np.array([reed_frost(N=N, p=p) for _ in range(500)])

plt.hist(sizes, bins=30, color="lightgrey", edgecolor="grey")
plt.xlabel("Total infected (out of 200)")
plt.title("500 simulated outbreaks")
plt.show()
# The histogram is bimodal: minor outbreaks fizzle out, major ones take off.

# Probability of a minor outbreak
print("fraction that fizzled (<20 infected):", np.mean(sizes < 20))

# Early on the epidemic behaves like a branching process; the probability q
# that it dies out solves   q = exp(R0 * (q - 1)).
q = brentq(lambda q: q - np.exp(R0 * (q - 1)), 0, 0.999)
print("theory:", round(q, 3))

"""
MathEpi 07 - Fitting a model to data (least squares)

Generate "observed" data from an SIR epidemic with known parameters, then
recover the transmission rate beta by choosing the value that makes the
model curve closest to the data.
"""
import numpy as np
from scipy.integrate import solve_ivp
from scipy.optimize import minimize_scalar
import matplotlib.pyplot as plt


def sir(t, y, beta, gamma, N):
    S, I, R = y
    return [-beta * S * I / N, beta * S * I / N - gamma * I, gamma * I]


N = 1000
gamma = 0.2                     # assume the infectious period is known (5 days)
days = np.arange(0, 61)


def model_I(beta):
    sol = solve_ivp(sir, (0, 60), [N - 1, 1, 0], args=(beta, gamma, N), rtol=1e-8, t_eval=days)
    return sol.y[1]


# Simulate noisy observations (Poisson noise around the true curve)
rng = np.random.default_rng(10)
true_beta = 0.5
observed = rng.poisson(model_I(true_beta))


# Least squares: pick the beta that minimises the sum of squared errors
def sse(beta):
    return np.sum((observed - model_I(beta)) ** 2)


fit = minimize_scalar(sse, bounds=(0.1, 1.0), method="bounded")
beta_hat = fit.x
print(f"estimated beta = {beta_hat:.4f}   (true {true_beta})")
print(f"estimated R0   = {beta_hat / gamma:.3f}   (true 2.5)")

plt.plot(days, observed, "ko", label="Observed")
plt.plot(days, model_I(beta_hat), "r-", label="Fitted SIR")
plt.xlabel("Day")
plt.ylabel("Infectious people")
plt.legend()
plt.show()

# The error curve has a clear minimum near the true beta
beta_grid = np.arange(0.3, 0.701, 0.01)
plt.plot(beta_grid, [sse(b) for b in beta_grid])
